# レイヤー画像エディタ

インストール不要・サーバー不要のブラウザ画像編集ツールです。`index.html` をダブルクリックして開くだけで動きます。
複数の画像をレイヤーとして重ね、1枚の画像（PNG / JPEG / WebP）として保存できます。

## 使い方

1. `index.html` をブラウザで開く
2. 「画像を開く」／ドラッグ&ドロップ／Ctrl+V で画像を読み込む（複数可、最初の画像がキャンバスサイズになります）
3. キャンバス上でレイヤーをドラッグして移動、ハンドルでリサイズ・回転
4. 右パネルでレイヤーの順序・表示・プロパティ（不透明度・合成モード・補正など）を調整
5. 「書き出し」で1枚の画像としてダウンロード

## 機能

- **レイヤー**: 移動 / リサイズ / 回転 / 左右・上下反転 / 不透明度 / 合成モード（乗算・スクリーン・オーバーレイ等16種）/ 表示切替 / ロック / 並べ替え（ドラッグ or ▲▼）/ 複製 / 名前変更
- **補正**（レイヤー単位）: 明るさ / コントラスト / 彩度 / 色相 / ぼかし / グレースケール / セピア / 階調反転
- **画像**: トリミング（範囲をドラッグ）/ 元のサイズに戻す / 比率を元に戻す
- **テキスト**: 複数行 / フォント / サイズ / 太字・斜体 / 揃え / 文字色 / 縁取り / 行間
- **図形**: 矩形（角丸）/ 楕円 / 線、塗り・線の色と太さ
- **キャンバス**: サイズ指定 / 背景（透明 or 色）/ 選択レイヤー・全レイヤーに合わせる / 範囲を指定して切り抜き
- **書き出し**: PNG / JPEG / WebP、品質、出力サイズ（倍率・幅・高さ指定）
- **Undo / Redo**: 50 段階

## 操作

| 操作 | 内容 |
|---|---|
| ドラッグ | レイヤーを移動（Shift: 水平/垂直に固定） |
| 角ハンドル | 比率を保ってリサイズ（Shift: 自由変形、Alt: 中心固定） |
| 辺ハンドル | 自由変形（Shift: 比率固定、Alt: 中心固定） |
| 上の丸ハンドル | 回転（Shift: 15° 刻み） |
| ホイール | ズーム |
| Space + ドラッグ / 中ボタンドラッグ | 表示位置を移動 |
| 矢印キー | 1px 移動（Shift: 10px） |
| Delete / Backspace | 選択レイヤーを削除 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直す |
| Ctrl+D | レイヤーを複製 |
| Ctrl+O | 画像を開く |
| Ctrl+S | 書き出し |
| Ctrl+0 | キャンバス全体を表示 |
| Ctrl+V | クリップボードの画像を貼り付け |
| Esc | トリミングを中止 / 選択解除 |
| Enter | トリミングを適用 |

## 対応ブラウザ

Chrome / Edge / Firefox の最新版を推奨します。
Safari は Canvas の `filter` に対応していないため「補正」が反映されません。

## 注意

- 作業内容はブラウザに保存されません。ページを閉じると失われるので、必要なら書き出してください。
- 画像はすべてブラウザ内で処理され、外部に送信されることはありません。
